# Cinco reglas de codificación del equipo

1. Nombres claros en español para funciones y variables (por ejemplo `calcular_copago`).
2. Cada función hace una sola cosa y no pasa de 20 líneas.
3. Primero se escribe la prueba y después el código (TDD).
4. Todo cambio entra por pull request con al menos una revisión.
5. Prohibido dejar contraseñas, claves o datos de pacientes en el código.
