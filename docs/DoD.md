# Definition of Done (6 criterios)

| # | Criterio | Atributo ISO 25010 | Evidencia |
|---|---|---|---|
| 1 | El código fue revisado y aprobado por otro compañero en un pull request | Mantenibilidad | Pull request aprobado |
| 2 | Tiene pruebas unitarias automáticas que pasan | Fiabilidad | Ejecución de pytest en verde |
| 3 | La cobertura del módulo es de al menos 80 % | Mantenibilidad | Reporte de pytest-cov |
| 4 | El workflow de CI terminó sin errores | Fiabilidad | Pestaña Actions en verde |
| 5 | No hay datos sensibles del paciente en el código ni en los logs | Seguridad | Revisión del pull request |
| 6 | Cumple los criterios de aceptación y el dueño del producto lo aceptó | Adecuación funcional | Historia movida a Hecho con visto bueno |
